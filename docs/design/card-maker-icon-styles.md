# Which icons feel like Card Maker?

The same top bar and left rail in five styles, using real icons from each set. Press the buttons in the last one to see the bounce. Pick a favourite, or mix: for example fantasy icons for the rail and rounded ones for small toolbar buttons.

## Today: lucide lines

Clean, thin, neutral. What the app uses now.

## Good to know

- Whichever set wins goes behind one icon file in the app, so it can be swapped again later.
- The fantasy and hand-drawn sets need a short credit line in the app's Help; both licences allow using them in the app.
- The hand-drawn set is missing a few tools (layers, highlighter, undo), so those would be drawn to match or taken from a similar set.
- Icons can also take colour from the chosen theme, so the new themes and icons work together.
