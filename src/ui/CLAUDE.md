# ui/ map: Card Maker interface
Spec: `.claude/rules/ui.md`. Pointer events only, no hover-only actions.
- `shell/`: Desktop/Tablet/Phone shells · `toolbar/`, `panels/` (left and right panes), `canvas/`
- `components/` (shared, `components/ui/` = shadcn) · `theme/` (`themes.json`) · `settings/`
- Views and dialogs: `home/`, `print/`, `export/`, `data/`, `find/`, `merge/`, `gallery/`, `keywords/`, `text/` (rich text editor)
- `actions/`: user actions and shortcuts · `uiStore.ts` · `pwa/`, `desktop/`, `onboarding/`
- `icons.tsx`, `gameIcons.gen.ts` (generated by `npm run icons:gen`)
