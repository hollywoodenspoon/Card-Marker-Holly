# Android app

The Android app runs on phones and tablets with Android 7 or newer. Like the desktop app, it saves each project as a folder of ordinary files, so you can copy projects between your phone and a computer. It has no internet permission at all and works fully offline.

## Install

The app is installed from an APK file rather than the Play Store. The APK will appear on the project's [Releases page](https://github.com/hollywoodenspoon/Card-Marker-Holly/releases) once signed releases start.

1. On your phone or tablet, download the file ending in `.apk` from the Releases page.
2. Open it. Android asks once whether your browser or file manager may **Install unknown apps**. Allow it, then go back and tap **Install**.
3. Open **Hearthside Cardworks**.

To update, install the newer APK the same way. It installs over the old version and your projects stay where they are.

## Choose a folder for your projects

The first time you start the app, it asks **Where should your projects go?**

1. Tap **Choose a folder**.
2. Tap **Documents**, then the new-folder button, and name the folder _Hearthside Cardworks_.
3. Tap **Use this folder** (and **Allow** if Android asks).

Each project becomes a folder inside it, in the same format as the desktop app (`project.json`, `images`, `fonts`). Copy a project folder to a computer by USB or with a sync app, and open it there with **Open folder**; it works the other way round too.

To change the folder later, go to the Home screen and tap ☰ → **Projects folder…**. **Open folder** on the Home screen adds a project folder from somewhere else.

> **Note:** If Android ever takes away the app's access to that folder, the app asks you to choose the folder again. Pick the same one and your projects come back.

## Saving

Saving is automatic, every few moments and also whenever you switch to another app. You don't need to do anything before closing the app.

## The Back button

Android's Back button (or back gesture) closes whatever is on top first: a menu, a sheet, then a full-screen view such as Print or the Vector Maker. In the editor with nothing open, Back takes you to the Home screen.

## Exports

When you export a PDF, card images, Tabletop Simulator files, a CSV file or a backup, Android's **Save to** screen opens so you can choose where the file goes, for example Downloads or a cloud drive.

## Deleting a project

Home → ⋯ → **Remove…** takes a project off the list and leaves its folder alone. If you tick **Also delete the folder and everything in it from this device**, the folder is deleted for good, because Android folders have no Trash.

## Using the app on a small screen

The phone layout puts the card in the middle of the screen with a toolbar along the bottom. See [The workspace](help:workspace) and [Touch gestures](help:touch).
