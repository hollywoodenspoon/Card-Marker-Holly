# Keyboard shortcuts

These are all the keys Hearthside Cardworks knows. On a Mac, use ⌘ wherever it says Ctrl, and Option wherever it says Alt.

Shortcuts don't act while you're typing in a box. The card editor's keys also stop while a dialog or a full-screen view (Print, Gallery, Card data, Vector Maker, Help) is open, so they never change the hidden card.

## Help

| Keys   | What it does                                 |
| ------ | -------------------------------------------- |
| [[F1]] | Open Help at the page about what's on screen |
| [[?]]  | Open Help (card editor)                      |

## Card editor

| Keys                           | What it does                                  |
| ------------------------------ | --------------------------------------------- |
| [[Ctrl+Z]]                     | Undo                                          |
| [[Ctrl+Shift+Z]] or [[Ctrl+Y]] | Redo                                          |
| [[Ctrl+D]]                     | Duplicate the selection                       |
| [[Delete]] or [[Backspace]]    | Delete the selection                          |
| [[Ctrl+A]]                     | Select every part that isn't locked           |
| [[Esc]]                        | Select nothing; stop editing text or cropping |
| Arrow keys                     | Nudge 0.5 mm                                  |
| [[Shift]] + arrow keys         | Nudge 5 mm                                    |
| [[Ctrl+G]]                     | Group the selection                           |
| [[Ctrl+Shift+G]]               | Ungroup                                       |
| [[Ctrl+H]]                     | Find and replace                              |
| [[Ctrl+V]]                     | Paste a picture from the clipboard            |
| [[Ctrl+=]]                     | Zoom in                                       |
| [[Ctrl+-]]                     | Zoom out                                      |
| [[Ctrl+0]]                     | Fit the card to the screen                    |

## Mouse on the card

| Keys                               | What it does                                           |
| ---------------------------------- | ------------------------------------------------------ |
| [[Shift]] or [[Ctrl]] + click      | Add to or remove from the selection                    |
| [[Shift]] + drag a handle          | Pictures: resize freely. Other parts: keep proportions |
| [[Alt]] + drag a handle            | Resize from the centre                                 |
| [[Shift]] + drag the rotate handle | Turn in 15° steps                                      |
| [[Space]] + drag                   | Pan                                                    |
| Middle mouse button + drag         | Pan                                                    |
| [[Ctrl]] + mouse wheel             | Zoom at the pointer                                    |
| Mouse wheel                        | Pan                                                    |
| Double-click                       | Edit text; choose or reposition a picture              |

## Vector Maker: commands

| Keys                           | What it does                                    |
| ------------------------------ | ----------------------------------------------- |
| [[Ctrl+Z]]                     | Undo                                            |

| [[Ctrl+D]]                     | Duplicate                                       |

## Vector Maker: while dragging

| Keys                                    | What it does                                      |
| --------------------------------------- | ------------------------------------------------- |
| [[Shift]] + click                       | Add to or remove from the selection               |
| [[Shift]] + drag to move                | Move straight across or straight down             |
| [[Shift]] + drag a handle               | Keep proportions                                  |
| [[Alt]] + drag a handle                 | Resize from the centre                            |
| Shapes: [[Shift]] + drag                | Equal width and height                            |
| Shapes: [[Alt]] + drag                  | Draw from the centre                              |
| Pen: [[Shift]]                          | Snap to 45°                                       |
| Pen or direct selection: [[Alt]] + drag | Break the handle (corner)                         |
| Pen: [[Space]] while dragging           | Move the point you're placing                     |
| Pen: hold [[Ctrl]]                      | Adjust points and handles without leaving the pen |
| Pen: [[Ctrl]] + click empty space       | End the path                                      |

## Android Back button

Closes the open menu or sheet first, then a full-screen view; in the editor it goes to the Home screen.
