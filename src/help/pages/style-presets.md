# Style presets

A style preset (shared style) is a named look for text, such as "Card title" or "Rules", that many texts can share. Change the style once and every text linked to it updates, on every template and card.

## What a style holds

A style keeps a text's font, size, colour, bold, italic, underline and letter spacing. If you set an outline or shadow while a text is linked, that is saved in the style too.

Alignment, line height, padding and auto-shrink belong to each text box, not the style, so a centred title and a left-aligned title can share one style.

## Making a style

1. Style a text the way you like it (see [Text](help:text)).
2. Select it, and in the properties panel find **Shared style**.
3. Press **+** (**New style from this text**), type a name, and press **Create**.

The text is now linked to the new style.

## Linking a text to a style

Select a text and choose the style in the **Shared style** list. The text takes on the style's look straight away. **None (own style)** unlinks it.

When a text is linked, the next section is named after the style, e.g. **Style · Rules**, instead of **Default style**, with a line such as "Changes below update every text using “Rules” (12 texts)".

## Changing a style

Select any text linked to the style and change the font, size, colour and so on in its style section (e.g. **Style · Rules**). Every linked text in the project changes with it, on all templates and cards.

> **Note:** Texts that come from a template are styled in template mode. On a card, those settings are greyed out; press **Edit template** first.

## Styling some words with a style

While editing text, the paintbrush in the toolbar (**Apply a style to the selection**) gives the selected words a style's font, size, colour and so on. This copies the look once: the words are not linked, so they don't change when the style changes later. The paintbrush only appears when the project has at least one style.

## Rename, detach and delete

With a linked text selected, the **Shared style** section has:

- **Rename**: gives the style a new name.
- **Detach**: unlinks this one text. It keeps its current look but no longer follows the style.
- **Delete**: removes the style after asking. Texts using it keep their current look and become unlinked.

Styles are saved with the project, and travel with exported templates and backup files.

> **Tip:** Make a style for each kind of text in your game before you build many templates: title, type line, rules, flavour text. Changing the rules font later then takes one click.
