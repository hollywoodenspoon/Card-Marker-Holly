# Text

Text on a card is rich text: every word can have its own font, size and colour. The box around the text sets where it sits, how it wraps and how it shrinks to fit.

## Adding text

Press **Add** in the top bar (on a phone, **Add** in the bottom bar) and choose **Text**. A text box appears in the middle of the card. Drag it into place and pull its handles to change the size of the box.

In template mode the text goes on the template, so every card using it gets it. In card mode it belongs to that card only. See [Templates and fields](help:templates).

## Editing text

1. Double-click the text on the card (double-tap on touch). You can also select it and press **Edit text** in the properties panel. On a new card, the template's starter text (such as "Card name") is selected, so typing replaces it.
2. Type. The text tools float just above the text (below it when there's no room). [[Enter]] starts a new paragraph.
3. Press [[Esc]] when you're done.

On a phone the text opens in a panel at the top of the screen with the toolbar above it, and the card below shows the result as you type. Tap **Done** to finish.

## Styling words

While you edit, a toolbar floats above the card. Select some words first, then use:

- **Font** and **Font size** (in points, pt)
- **Text colour**
- **Bold**, **Italic**, **Underline** (or [[Ctrl+B]], [[Ctrl+I]], [[Ctrl+U]]; ⌘ on Mac)
- **Align left**, **center**, **right** or **justify** for the paragraph
- **Line height** (↕) and **Letter spacing** (↔, in em)
- **Apply a style to the selection** (paintbrush), when the project has [style presets](help:style-presets)
- **Insert symbol** ({ } button), see [inline symbols](help:keywords-numbers#inline-symbols)

## Default style

With a text selected (not editing), the properties panel on the right (**Edit** on a phone) has a **Default style** section. It sets the look of the whole text: **Font**, **Size**, **Colour**, **Bold**, **Italic**, **Underline**, horizontal alignment, **Vertical align** (top, middle, bottom), **Line height**, **Spacing** and **Padding** (space between the box edge and the text, in mm).

> **Note:** On a card, a text that comes from the template takes its layout and default style from the template. You can still type and style the words for this card. To change the box or default style, press **Edit template**. **Use template default text** puts the template's words back.

## Auto-shrink

Turn on **Shrink text to fit the box** in the **Auto-shrink** section. When the words don't fit, all text sizes shrink together until they do, but never below **Smallest size** (pt). If the text still doesn't fit, a red dashed box appears around it on the card. Make the box bigger, cut some words, or lower the smallest size.

Auto-shrink is set per text box, so a rules box can shrink while the title stays the same size.

## Outline and shadow

The **Effects** section adds:

- **Outline**: pick a colour, then set **Outline width**.
- **Shadow**: pick a colour, then set **Shadow X**, **Shadow Y** and **Opacity**.

Sizes are a percentage of the font size, so effects grow and shrink with the text, also when it auto-shrinks. Shadows are sharp (no blur), so they print exactly as you see them. Choose none in a colour box to turn an effect off.

## Keywords in this text

Words from your project's keyword list are styled automatically. To stop that in one text, such as a title, turn off **Style keywords in this text** in the **Keywords** section. See [Keywords, card numbers and symbols](help:keywords-numbers).
