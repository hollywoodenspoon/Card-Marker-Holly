# Keyboard shortcuts

These are all the keys Hearthside Cardworks knows. On a Mac, use ⌘ wherever it says Ctrl, and Option wherever it says Alt.

Shortcuts don't act while you're typing in a box. The card editor's keys also stop while a dialog or a full-screen view (Print, Card data, Help) is open, so they never change the hidden card.

## Help

| Keys   | What it does                                 |
| ------ | -------------------------------------------- |
| [[F1]] | Open Help at the page about what's on screen |
| [[?]]  | Open Help (card editor)                      |

## Card editor

| Keys                           | What it does                                  |
| ------------------------------ | --------------------------------------------- |
| [[Ctrl+Z]]                     | Undo                                          |
| [[Ctrl+Shift+Z]] or [[Ctrl+Y]] | Redo                                          |
| [[Ctrl+D]]                     | Duplicate the selection                       |
| [[Delete]] or [[Backspace]]    | Delete the selection                          |
| [[Ctrl+A]]                     | Select every part that isn't locked           |
| [[Esc]]                        | Select nothing; stop editing text or cropping |
| Arrow keys                     | Nudge 0.5 mm                                  |
| [[Shift]] + arrow keys         | Nudge 5 mm                                    |
| [[Ctrl+G]]                     | Group the selection                           |
| [[Ctrl+Shift+G]]               | Ungroup                                       |
| [[Ctrl+H]]                     | Find and replace                              |
| [[Ctrl+V]]                     | Paste a picture from the clipboard            |
| [[Ctrl+=]]                     | Zoom in                                       |
| [[Ctrl+-]]                     | Zoom out                                      |
| [[Ctrl+0]]                     | Fit the card to the screen                    |

## Mouse on the card

| Keys                               | What it does                                           |
| ---------------------------------- | ------------------------------------------------------ |
| [[Shift]] or [[Ctrl]] + click      | Add to or remove from the selection                    |
| [[Shift]] + drag a handle          | Pictures: resize freely. Other parts: keep proportions |
| [[Alt]] + drag a handle            | Resize from the centre                                 |
| [[Shift]] + drag the rotate handle | Turn in 15° steps                                      |
| [[Space]] + drag                   | Pan                                                    |
| Middle mouse button + drag         | Pan                                                    |
| [[Ctrl]] + mouse wheel             | Zoom at the pointer                                    |
| Mouse wheel                        | Pan                                                    |
| Double-click                       | Edit text; choose or reposition a picture              |

## Editing text

| Keys                          | What it does             |
| ----------------------------- | ------------------------ |
| [[Ctrl+B]]                    | Bold                     |
| [[Ctrl+I]]                    | Italic                   |
| [[Ctrl+U]]                    | Underline                |
| [[Ctrl+Shift+L]]              | Align left               |
| [[Ctrl+Shift+E]]              | Align centre             |
| [[Ctrl+Shift+R]]              | Align right              |
| [[Ctrl+Shift+J]]              | Justify                  |
| [[Ctrl+Z]] / [[Ctrl+Shift+Z]] | Undo or redo your typing |
| [[Enter]]                     | New paragraph            |
| [[Esc]]                       | Finish editing           |

## Number boxes

| Keys                        | What it does              |
| --------------------------- | ------------------------- |
| Up / down arrow             | Step the value up or down |
| [[Shift]] + up / down arrow | Step 10 times as far      |
| [[Enter]]                   | Confirm                   |

## Print preview

| Keys                                   | What it does                                            |
| -------------------------------------- | ------------------------------------------------------- |
| [[Space]] + drag, or middle mouse drag | Pan                                                     |
| [[Ctrl]] + mouse wheel                 | Zoom                                                    |
| Mouse wheel                            | Pan or scroll                                           |
| [[Ctrl+=]] / [[Ctrl+-]]                | Zoom in or out                                          |
| [[Ctrl+0]]                             | Fit                                                     |
| [[Esc]]                                | Close Print, Card data or Help                          |
