# Sticker sheet

35 stickers of 1.5 in (38.1 mm) on one A4 transparent sticker sheet. There are 7 of each design: three mechs, the jet and the Village Wizard hat.

- `stickers.pdf`: print at 100% ("Actual size"). Very faint corner ticks mark each 1.5 in square for cutting. There is no background, so the white areas stay clear.
- `stickers.png`: a preview.
- `assets/`: the art, with the white background removed.

Rebuild from the repo root with `node game/sticker-sheet/build.mjs`.

## Logo stickers

`logo-stickers.pdf` has 20 Urban Warfare Edition logos in the game's red, each 86 x 23.8 mm (almost a card's 88 mm height), with the same faint corner ticks. Rebuild with `node game/sticker-sheet/build-logo.mjs`.
